# How to Split a PDF into Individual Pages

PDF Splitter creates a separate PDF for every page in your document. It is useful when colleagues, students, or clients need only one page from a longer file.

## Steps

1. Open [the PDF Splitter tool](/pdf-tools/pdf-splitter).
2. Upload the PDF and follow the on-screen options.
3. Download the result and check it before sharing.

## Tips for better results

Give downloaded files clear names before sharing. Keep the original document if you might need to split it again with different pages.

## Use the tool

Ready to begin? Open [the PDF Splitter tool](/pdf-tools/pdf-splitter) and process your PDF in the browser.
